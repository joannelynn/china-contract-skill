
## 第二条 试用期

```
【有试用期】
试用期自 {{probation_start}} 至 {{probation_end}}，共 {{probation_months}} 个月。
试用期工资为人民币 {{probation_salary}} 元/月（税前）。

【无试用期】
本合同不设试用期。
```

## 第三条 工作内容和工作地点

```

{{job_responsibilities|（可由用人单位另行制定岗位说明书）}}

```

---

## 第四条 工作时间和休息休假

```
工作时间制度：{{work_hour_system}}
（选项：标准工时制 / 综合工时制 / 不定时工时制）

【标准工时制】
乙方执行标准工时制度，每日工作时间不超过8小时，
每周工作时间不超过40小时，每周至少休息一天。

【综合工时制】
乙方执行综合工时制度，以{{calculation_period|月/季/年}}
为周期综合计算工作时间，平均每日不超过8小时，
平均每周不超过40小时（须经劳动行政部门审批）。

年带薪年假：按乙方累计工作年限依法享有（1-10年享5天，
10-20年享10天，20年以上享15天）。
法定节假日：按国家规定执行，共11天。
```

## 第五条 劳动报酬

```
乙方月基本工资为人民币 {{monthly_salary}} 元（税前）。

工资发放日期：每月 {{salary_day|15}} 日前，
以货币形式（银行转账）支付至乙方指定账户。

加班工资标准（标准工时制适用）：
- 工作日延长工作时间：正常工资的150%
- 休息日安排工作（不补休）：正常工资的200%
- 法定节假日安排工作：正常工资的300%

{{bonus_clause|绩效奖金及其他激励报酬，由甲方依据公司薪酬制度另行规定。}}
```

## 第六条 社会保险和福利

```
甲方依法为乙方缴纳社会保险（养老、医疗、失业、
工伤、生育保险）及住房公积金（如适用），
缴纳基数和比例按用人单位所在地相关规定执行。

乙方个人应缴纳的社会保险费及住房公积金，
由甲方从乙方工资中代为扣缴。

其他福利待遇：{{other_benefits|按公司现行规定执行。}}
```

---

## 第七条 劳动保护和劳动条件

```
甲方应为乙方提供必要的劳动保护措施，
依法改善劳动条件，保障乙方的人身安全和身体健康。

乙方应遵守安全操作规程，正确使用劳动保护用品。
```

---

## 第八条 劳动纪律

```
乙方应遵守甲方依法制定的规章制度和劳动纪律，
包括但不限于考勤制度、保密制度和职业行为规范。

甲方规章制度已通过民主程序制定并公示，
乙方已知悉并同意遵守。
```

---

## 第九条 保密义务（可选）

```
【如需保密条款】
乙方在职期间及离职后{{confidentiality_period|2年}}内，
对在职期间获悉的甲方商业秘密、技术秘密及其他保密信息
负有保密义务，不得向任何第三方披露或用于任何其他目的。
```

---

## 第十条 竞业限制（可选，仅限高管/技术人员/知悉商业秘密者）

```
【如需竞业限制条款】
乙方离职后 {{non_compete_period|12}} 个月内，
不得在与甲方存在竞争关系的单位任职，
不得自行开展与甲方存在竞争关系的业务。

甲方自乙方离职之日起，每月向乙方支付竞业限制补偿金
人民币 {{non_compete_compensation}} 元，直至竞业限制期届满。

乙方违反本条约定，应向甲方支付违约金
人民币 {{non_compete_penalty}} 元，并赔偿甲方实际损失。
```

---

## 第十一条 合同解除和终止

```
本合同的解除和终止，依照《中华人民共和国劳动合同法》
第三十六条至第五十条的规定执行。

经济补偿金按乙方在甲方工作年限，
每满一年支付一个月工资的标准计算；
不满六个月的，支付半个月工资；
满六个月不足一年的，按一年计算。
```

---

## 第十二条 争议解决

```
双方因履行本合同发生劳动争议，应协商解决；
协商不成的，可向用人单位所在地劳动争议仲裁委员会申请仲裁。
对仲裁裁决不服的，可依法向人民法院提起诉讼。
```
