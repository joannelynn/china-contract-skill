# 中国合同法律条款参考库

## 一、劳动合同法定必备条款（《劳动合同法》第17条）

生成劳动合同时，以下条款为法定必备，缺一不可：

1. 用人单位的名称、住所和法定代表人或者主要负责人
2. 劳动者的姓名、住址和居民身份证或者其他有效身份证件号码
3. 劳动合同期限
4. 工作内容和工作地点
5. 工作时间和休息休假
6. 劳动报酬
7. 社会保险
8. 劳动保护、劳动条件和职业危害防护
9. 法律、法规规定应当纳入劳动合同的其他事项

---

## 二、试用期规定（《劳动合同法》第17-21条）

### 试用期上限
| 合同期限 | 最长试用期 |
|----------|-----------|
| 3个月以上不满1年 | 1个月 |
| 1年以上不满3年 | 2个月 |
| 3年以上或无固定期限 | 6个月 |
| 以完成一定工作任务为期限 | 不得约定试用期 |
| 非全日制用工 | 不得约定试用期 |

### 试用期工资
- 不得低于本单位相同岗位最低档工资的 **80%**
- 不得低于用人单位所在地的**最低工资标准**
- 以上两个条件取**较高者**

### 重要限制
- 同一用人单位与同一劳动者**只能约定一次**试用期
- 试用期包含在劳动合同期限内

---

## 三、社会保险义务（《社会保险法》）

用人单位必须为劳动者缴纳五项社会保险（"五险"）：

| 险种 | 说明 |
|------|------|
| 基本养老保险 | 企业承担约16-20%，个人承担8% |
| 基本医疗保险 | 比例因地区而异 |
| 失业保险 | 企业0.5-1%，个人0.5% |
| 工伤保险 | 企业承担（0.2-1.9%，按行业），个人不缴纳 |
| 生育保险 | 部分地区已并入医疗保险 |

> ⚠️ 具体缴纳比例因城市不同差异较大，应以当地社保局规定为准。

## 四、工资支付规定（《工资支付暂行规定》）

```
标准条款文本（可直接引用）：
"甲方应于每月____日前以货币形式足额支付乙方工资。
工资支付周期不得超过一个月。如遇节假日或休息日，
应提前在最近工作日支付。"
```

### 加班工资标准
- 工作日延长工作时间：正常工资的 **150%**
- 休息日安排工作（不能补休）：正常工资的 **200%**
- 法定节假日安排工作：正常工资的 **300%**

## 五、解除合同条款

### 劳动者可随时解除（《劳动合同法》第38条）
用人单位有下列情形之一，劳动者可立即解除并要求经济补偿：
- 未按约定提供劳动保护或劳动条件
- 未及时足额支付劳动报酬
- 未依法缴纳社会保险费
- 规章制度违反法律、法规，损害劳动者权益

### 用人单位可解除（《劳动合同法》第39条）— 无需补偿
- 试用期内被证明不符合录用条件
- 严重违反用人单位规章制度
- 严重失职、营私舞弊，造成重大损害
- 同时与其他用人单位建立劳动关系，对完成工作任务造成严重影响
- 被依法追究刑事责任

### 用人单位提前30天通知可解除（《劳动合同法》第40条）— 需支付经济补偿
- 劳动者患病或非工受伤，医疗期满后不能从事原工作
- 劳动者不能胜任工作，培训或调岗后仍不胜任
- 劳动合同订立时所依据的客观情况发生重大变化

## 六、经济补偿金（《劳动合同法》第47条）

**计算公式：**
```
经济补偿金 = 工作年限 × 月平均工资

工作不满6个月 → 补偿0.5个月工资
满6个月不足1年 → 补偿1个月工资
每满1年 → 补偿1个月工资
```

**上限：**
- 月工资高于当地职工平均工资3倍的，按3倍计算
- 补偿年限最高不超过12年（仅适用于上限封顶情形）

---

## 七、违约金限制（《劳动合同法》第25条）

**劳动合同中只能在以下两种情况约定违约金，其他情况无效：**

1. **服务期违约金**：用人单位为劳动者提供专项培训，可约定服务期及违约金，违约金不得超过培训费用
2. **竞业限制违约金**：竞业限制期限不超过2年，用人单位需按月支付补偿金

> ⚠️ 不得约定劳动者主动离职的违约金，否则条款无效。

---

## 八、竞业限制标准条款

```
竞业限制条款（可选）：
"乙方在职期间及离职后____个月内，不得在与甲方存在竞争关系
的企业任职，不得自行设立与甲方存在竞争关系的企业。
甲方应自乙方离职之日起，按月向乙方支付竞业限制补偿金，
金额不低于乙方离职前十二个月平均工资的____%。
若乙方违反本条约定，应向甲方支付违约金人民币____元。"
```

竞业限制适用对象：高级管理人员、高级技术人员、其他知悉商业秘密的人员。

## 九、服务合同核心条款（《民法典》第770-800条）

### 服务合同必备要素
1. 服务内容、质量要求和验收标准
2. 服务期限（起止日期）
3. 价款或报酬及支付方式
4. 违约责任
5. 争议解决方式及适用法律

### 付款方式标准表达
```
"甲方应按以下方式向乙方支付服务费用：
- 合同签署后____个工作日内，支付合同总金额____%作为预付款
- 服务完成并经甲方验收后____个工作日内，支付剩余____%"
```

### 知识产权归属（服务合同）
```
"乙方在本合同服务期间为甲方创作的全部工作成果，
包括但不限于设计、代码、文档、报告等，
其知识产权归属[甲方/乙方]所有。"
```

## 十、通用争议解决条款

### 劳动合同（推荐）
```
"双方因履行本合同发生争议，应首先协商解决；
协商不成的，可向用人单位所在地劳动争议仲裁委员会申请仲裁。
对仲裁裁决不服的，可向人民法院提起诉讼。"
```

> 注：劳动合同争议必须先仲裁，不得直接诉讼。

### 服务合同（推荐）
```
"双方因履行本合同发生争议，应首先友好协商；
协商不成的，提交[甲方所在地/乙方所在地/合同签订地]
人民法院管辖，或提交____仲裁委员会仲裁（二选一）。"
```
